# security-ai-agent

An AI agent that protects our own machines. It watches files, programs and network traffic, inspects settings, code and dependencies, researches the latest security information on the web, defends actively, and attacks our own machines to find holes before others do.

## The frame (fixed; only the user changes it)

- **Models:** use existing models; do not build one.
- **Scope:** the user decides which machines are in scope. Watch, defend and attack only those machines.
- Never run heavy work on the machine you run on.
